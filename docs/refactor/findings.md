Each item's status is in its trailing marker, checked against the code after the refactor: `— done` (fixed), `— gone` (the code was deleted), `— declined` (deliberately not done, with the reason), `— reported` (a bug, still present), `— open` (a product question, still undecided), `— todo` (still true, not addressed). Paths are as the reviewers wrote them: bare renderer paths sit under `apps/desktop/src/renderer/src`, `plugins/…` paths under `apps/desktop/src`.
